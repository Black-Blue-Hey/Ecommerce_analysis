# E-Commerce SQL Business Analysis

## Project Overview

This project analyzes an e-commerce dataset using **MySQL** to identify business insights related to revenue, customers, products, sales channels, monthly performance, and refunds.

The analysis was performed using the `anal` table.

## Business Questions

The analysis covers:

- Overall revenue, refunded amount, net revenue, and refund rate
- Country and sales channel performance
- Product revenue, quantity, and AOV
- Top customers by revenue and AOV
- One-time vs repeat customer analysis
- Monthly revenue and refund trends
- Product performance across channels and countries
- Refund analysis by product, channel, customer, and country

## Key Results

|         Metric                |   Result   |
|-------------------------------|------------|
| Completed Revenue             | 278,127.90 |
| Refunded Amount               | 95,286.45  |
| Net Revenue                   | 182,841.45 |
| Refund Rate                   | 24.93%     |
| Repeat Customer Revenue Share | 79.29%     |

### Key Insights

- Repeat customers contributed **79.29%** of completed revenue.
- The **United Kingdom** generated the highest completed revenue.
- **Trekking Poles** generated the highest completed product revenue.
- **Paid Search** had the highest completed order volume.
- **Organic** had the highest AOV among sales channels.

> **Currency Note:** The dataset contains multiple currencies. Combined monetary figures should not be interpreted as a single-currency value unless the currencies are standardized.
